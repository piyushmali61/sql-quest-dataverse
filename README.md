## 🎮 How to Play

### Option 1: Play Online Instantly (No Installation!)
You can play the game directly in your browser:
👉 **[Play SQL Quest Online](https://piyushmali61.github.io/sql-quest-dataverse/)**

---

### Option 2: Play Locally on Your Computer (Offline)

#### On Windows:
1. **Download or Clone** this repository to your computer.
2. Double-click **`setup.bat`** (verifies that Node.js or Python is installed).
3. Double-click **`start.bat`**!  
   *Your default web browser will automatically open to http://localhost:3000 and the game starts immediately!*

#### On macOS / Linux:
1. Open terminal in the downloaded folder.
2. Run:
   ```bash
   chmod +x setup.sh start.sh
   ./start.sh
   ```
   *The game launches automatically in your default browser.*

## 🌌 The Story: Lost in the DataVerse
The DataVerse—a simulated universe where all knowledge is stored in relational schemas—has been struck by a catastrophic system anomaly known as the **Syntax Null**.

Guided by **BYTE** (your floating AI companion), you must venture across 14 corrupted zones, restore damaged database tables, crack SQL mysteries, and face off in the Tournament Arena to save the digital realm!

---

## 🗺️ Game Features

- **14 Epic Adventure Zones (84 Missions)**:
  1. *The Forgotten Schema* — DQL basics (`SELECT`, `WHERE`, `ORDER BY`, `LIMIT`)
  2. *The Relational Ruins* — Multi-table Joins (`INNER`, `LEFT`, `RIGHT`, `FULL`)
  3. *The Aggregate Abyss* — Statistical queries (`COUNT`, `SUM`, `AVG`, `GROUP BY`, `HAVING`)
  4. *The Subquery Sanctum* — Nested queries, `IN`, `EXISTS`, Correlated Subqueries
  5. *The Modification Matrix* — DML mutations (`INSERT`, `UPDATE`, `DELETE`)
  6. *The Constraint Colosseum* — Advanced constraints, conditional logic, and set operations
  7. *The Window Watchtower* — Analytical window functions (`ROW_NUMBER`, `RANK`, partitions)
  8. *The CTE Crypt* — Common Table Expressions (`WITH`) and modular query graphs
  9. *The Set Citadel* — Advanced set unions, intersections, and multi-source reconciliations
  10. *The Transaction Core* — High-concurrency operations and consistency
  11. *The Schema Forge* — DDL architecture (`CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`, constraints)
  12. *Chronos Vault* — Temporal SQL (`strftime`, date arithmetic, timestamps, interval analytics)
  13. *View Horizon* — Virtual views, multi-table projections, and cached data pipelines
  14. *The Anomaly Singularity* — Hierarchical tree traversals (`WITH RECURSIVE`), running aggregates, lag/lead, and the Grandmaster Convergence Boss

- **🧪 SQL Practice Lab (5-Minute Preview Session)**:
  - Freeform query sandbox with live relational database environments, instant presets, and interactive cheat sheets (5-minute public session preview that starts on launch). Continued learning available at [SSBT Ignite Portfolio](https://ssbt-ignite-portfolio.onrender.com/).
